# Car Price Prediction Using Linear Regression

## Project Overview
This project uses machine learning to predict car prices based on different vehicle features.

The dataset contains information about cars such as brand, price, body type, mileage, engine volume, engine type, registration and year.

## Objective
The objective of this project is to build a Linear Regression model that can predict car prices using the available vehicle features.

## Dataset
The dataset contains 4,345 car records and includes features such as:
- Brand
- Price
- Body
- Mileage
- Engine Volume
- Engine Type
- Registration
- Year
- Model

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Statsmodels
- Scikit-learn

## Project Workflow
1. Load the dataset
2. Explore and understand the data
3. Handle missing values
4. Prepare the data for modelling
5. Build a Linear Regression model
6. Evaluate the model

## Machine Learning Model
Linear Regression was used to model the relationship between car features and car prices.
